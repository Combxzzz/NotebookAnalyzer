O projeto funcionará como um sistema integrado para coletar, armazenar, analisar e apresentar informações sobre diferentes notebooks. O processo começará com a inicialização de um notebook por meio de um Live Linux, onde será executado um script Bash responsável por coletar automaticamente informações sobre o computador. Esse script utilizará ferramentas disponíveis no Linux para identificar componentes e características como processador, memória RAM, GPU, armazenamento, saúde do SSD ou HDD, bateria, temperaturas e resultados de benchmarks.

Depois de coletar essas informações, o Bash organizará os dados em um formato JSON. Esse JSON será enviado por meio de uma requisição HTTP para a API principal desenvolvida em Java com Spring Boot. A API será responsável por receber e validar os dados e, em seguida, armazená-los em um banco de dados PostgreSQL. Dessa forma, cada notebook poderá ser registrado juntamente com seus respectivos testes e informações coletadas.

Quando o usuário quiser consultar os resultados, o frontend, desenvolvido inicialmente apenas com HTML, CSS e JavaScript, fará uma requisição para a API Spring Boot. Por exemplo, ao solicitar o ranking dos notebooks com melhor desempenho, o Spring Boot encaminhará essa solicitação para uma segunda API desenvolvida em Python utilizando FastAPI. Esse serviço será responsável pela parte de análise dos dados.

A API Python poderá consultar os dados armazenados no PostgreSQL e utilizar bibliotecas como Pandas e NumPy para realizar os cálculos necessários. A partir dos dados coletados, serão calculados diferentes indicadores, como desempenho, conservação, saúde da bateria e armazenamento. Esses indicadores poderão ser combinados para gerar um score geral para cada notebook. Depois dos cálculos, o Python organizará os computadores de acordo com o critério solicitado e retornará os resultados em JSON para o Spring Boot.

Por fim, o Spring Boot entregará os resultados ao frontend, que ficará responsável por apresentar as informações de forma visual ao usuário. A interface poderá mostrar os notebooks cadastrados, suas especificações, resultados dos testes, scores, rankings e comparações entre diferentes computadores.

Dessa forma, cada tecnologia terá uma responsabilidade específica dentro do sistema: o Bash será responsável pela coleta dos dados, o JSON pela comunicação, o Spring Boot pelo gerenciamento da aplicação e da API principal, o PostgreSQL pelo armazenamento, o Python pela análise dos dados e o HTML, CSS e JavaScript pela apresentação das informações ao usuário. O projeto será desenvolvido inicialmente para analisar no máximo cerca de 20 notebooks, permitindo priorizar uma arquitetura organizada e modular sem a necessidade de preocupações com grande escala.
